# Fashion App - E-commerce de Ropa 🛍️🧥

Bienvenido al repositorio de **Fashion App**, una aplicación de comercio electrónico diseñada para explorar, ver detalles y comprar prendas de vestir modernas y a la moda. Esta interfaz de usuario (UI) proporciona una experiencia de compra fluida y visualmente atractiva, ideal para dispositivos móviles.

---

## 🚀 Características Principales

*   **Pantalla de Inicio (`index.html`):** 
    *   Saludo personalizado para el usuario.
    *   Barra de búsqueda interactiva.
    *   Filtrado de productos por categorías (Todos, Vestidos, Camisetas, Jeans).
    *   Listado de productos populares con información de precio y calificación.
    *   Menú de navegación inferior.
*   **Detalle de Producto (`views/detail.html`):**
    *   Vista detallada de una prenda seleccionada.
    *   Información adicional del producto.
*   **Proceso de Compra (`views/checkout.html`):**
    *   Pantalla dedicada al resumen de compra o proceso de validación.
*   **Diseño Responsivo (Mobile-First):** Interfaz optimizada e intuitiva pensada predominantemente para pantallas de teléfonos móviles.
*   **Estilo Moderno:** Interfaz limpia utilizando variables de CSS y estilos modulares para facilitar el mantenimiento y lograr un look atractivo (Glassmorphism, tarjetas, etc).

---

## 🛠️ Tecnologías Utilizadas

Este proyecto es estrictamente de frontend y no requiere lenguajes de servidor o librerías pesadas, garantizando una carga rápida y alto rendimiento:

*   **HTML5:** Estructura semántica del contenido.
*   **CSS3:** Estilos completos, uso de `variables.css` para colores/fuentes estandarizados y diseño moderno.
*   *(Sin dependencias externas ni frameworks de JavaScript)*

## ⚙️ Instalación y Uso Local

Al ser un proyecto estático de HTML y CSS, no necesitas instalar entornos complejos como Node.js o bases de datos.

1.  **Clonar este repositorio** o descargar la carpeta en tu computadora local.
2.  **Abrir el proyecto:**
    *   Si usas **Visual Studio Code**, es muy recomendable instalar la extensión **"Live Server"**. Haz clic derecho sobre `index.html` y selecciona *"Open with Live Server"*.
    *   Alternativamente, puedes simplemente darle doble clic al archivo `index.html` para abrirlo directamente en tu navegador web de preferencia (Chrome, Firefox, Safari, Edge).
